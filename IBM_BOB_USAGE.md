# IBM Bob Usage in FINOVA – SmartSpend

## Overview

FINOVA – SmartSpend is an AI-assisted personal budget planner developed to help users manage their monthly budgets, track expenses and understand their spending patterns.

IBM Bob was used as an AI-assisted development environment throughout the project lifecycle.

## 1. Project Planning

IBM Bob Plan mode was used to analyze the project requirements and break the problem into smaller development tasks.

The planning process helped define:
- Application structure
- Core modules
- Budget management functionality
- Expense tracking
- Spending insights
- Data persistence
- Testing requirements

## 2. Application Development

IBM Bob Agent mode was used to assist in implementing the Python-based SmartSpend application.

The project was developed using:
- Python
- Streamlit
- Object-Oriented Programming
- JSON-based data persistence
- Automated testing using pytest

IBM Bob assisted with implementing and refining different modules including budget management, expense tracking, spending insights, data storage and exception handling.

## 3. Debugging and Refinement

IBM Bob was also used during development to identify issues, understand errors and refine the implementation.

The development workflow involved reviewing the generated implementation, testing the functionality and making corrections where required.

## 4. Testing

IBM Bob assisted with preparing and reviewing test cases for important application components.

The project includes pytest-based tests covering areas such as:
- Spending insights
- Models
- Data storage

The application was also run locally to verify its functionality and user interface.

## 5. Final Application

The completed SmartSpend application provides users with functionality for managing budgets, recording expenses and obtaining spending-related insights through a simple interface.

IBM Bob supported the project from planning through implementation, debugging and testing, helping the team develop and refine the working prototype.
